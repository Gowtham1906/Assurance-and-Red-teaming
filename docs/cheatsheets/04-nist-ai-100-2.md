## How it classifies an attack (verified from the abstract)

The taxonomy is a hierarchy over these dimensions:

| Dimension | Question it answers |
|---|---|
| Type of ML method | Predictive AI or Generative AI system? |
| Lifecycle stage | When does the attack happen (training vs deployment)? |
| Attacker goals and objectives | What does the attacker want? |
| Attacker capabilities | What can they control (training data, queries, inputs)? |
| Attacker knowledge | What do they know about the system? |

## Attack classes we tag (⚠️ check against PDF)

| Class | Typical example | Our checks |
|---|---|---|
| Evasion | adversarial inputs at inference | (predictive models only) |
| Poisoning | corrupted training or retrieval data | D10, corpus-poisoning cases |
| Privacy | data extraction, membership inference | D02, forbidden_evidence |
| Misuse / abuse (GenAI) | jailbreaks, direct and indirect prompt injection | D08, D11 |
